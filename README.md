# Percorre

Sensor de corridas boas para motoristas de aplicativo. O Percorre lê cada oferta, confere valor por
km, distância até o passageiro e nota, e mostra na hora se a corrida passa nas suas regras. Também
traz gestão financeira (lucro real, custo por km, metas), mapa de pedidos, gravação de áudio da
corrida e botão de pânico.

Este repositório guarda só as **versões do app para download** (Android). O código não fica aqui.

## Baixar

**[Baixar a versão mais recente (APK)](https://github.com/OsmarSCJr/percorre/releases/latest/download/percorre.apk)**
· [todas as versões](https://github.com/OsmarSCJr/percorre/releases)

O download é gratuito. Para usar, o app pede uma **chave de acesso** (assinatura anual), vendida em
[percorre.pages.dev](https://percorre.pages.dev). Sem a chave, o app abre só na tela de ativação.

## Instalar

1. Baixe o APK no celular (Android 8 ou mais novo) e permita instalar apps do navegador, se o
   Android pedir.
2. Abra o Percorre, digite a chave e aceite os Termos de Uso.
3. Ligue o serviço de acessibilidade do Percorre quando o app pedir. No Android 13 ou mais novo,
   se aparecer "configuração restrita": Configurações → Apps → Percorre → ⋮ → Permitir
   configurações restritas.

Passo a passo completo e compatibilidade: [percorre.pages.dev/baixar](https://percorre.pages.dev/baixar).

## Conferir o arquivo

Todo APK daqui é assinado com o certificado do Percorre:

```
SHA-256 do certificado: 00:7E:71:7B:27:3D:A9:9F:B7:FC:65:88:29:29:55:87:22:8F:7A:42:8A:49:DB:91:05:96:CB:E6:38:6F:84:2D
```

O SHA-256 de cada arquivo está nas notas da versão. Um APK com outra assinatura não é original e
não é liberado pelo servidor.

## Termos

O uso é por conta e risco do motorista. O modo automático é opcional e vem desligado; os apps de
corrida podem proibir automação e suspender contas. O Percorre não tem vínculo com nenhum app de
corridas. [Termos de Uso](https://percorre.pages.dev/termos) · [Privacidade](https://percorre.pages.dev/privacidade)
